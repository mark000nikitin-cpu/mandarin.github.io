# Сова

**Читай. Расти. Возвращайся.**

Мобильная читалка с книжными сериями (сагами) и бережной мотивацией в духе Duolingo: XP, огонёк-серия, цель дня, задания, достижения, заморозки и читательская лига.

Приложение работает офлайн, не требует сборки и не использует внешних библиотек, шрифтов или интернета. Внутри — оригинальная демо-библиотека из трёх саг, семи книг и девятнадцати глав с вопросами после глав.

## Быстрый запуск

Нужен любой статический сервер. Например, встроенный PowerShell-сервер из проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1
```

Откройте <http://127.0.0.1:8123/>.

Другие варианты:

```powershell
# Python
python -m http.server 8123

# Node.js
npx serve -l 8123 .
```

### Демо-профиль

- Нажмите «Сначала посмотреть демо-профиль» на первом экране.
- Или откройте <http://127.0.0.1:8123/?seed=demo>.
- Демо можно сбросить в профиле: «Начать заново».

## Установка на Android

Сова — PWA. Установка доступна только по **HTTPS** или на **localhost**.

1. Опубликуйте папку проекта на любом статическом хостинге с HTTPS: GitHub Pages, Netlify, Cloudflare Pages, Vercel.
2. Откройте сайт в Chrome на Android.
3. Меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Для проверки с компьютера без публикации можно включить USB-отладку и проброс порта: `chrome://inspect/#devices` → Port forwarding → `8123 → localhost:8123`, затем открыть `http://localhost:8123` в Chrome на телефоне.

После установки приложение открывается без адресной строки и работает офлайн. Повторный визит после первого запуска обслуживает service worker.

### Почему не `file://`

При открытии `index.html` двойным щелчком интерфейс и чтение работают, но:

- service worker не регистрируется — офлайн-режим и установка недоступны;
- поведение `localStorage` в файловом протоколе зависит от браузера.

Для полноценной работы нужен HTTP/HTTPS.

## Что внутри

### Чтение

- Читалка с темами «Светлая», «Сепия», «Ночь», размером текста и межстрочным интервалом.
- Прогресс главы по прокрутке, автосохранение позиции.
- Озвучивание главы через Web Speech API (голоса зависят от устройства и браузера).
- Вопрос после каждой главы, пояснение к ответу, возможность пропустить.
- Награды за главу и книгу, переход к следующей главе или книге.
- Импорт своих книг: вставить текст или загрузить `.txt` / `.md`. Заголовки глав — `## Название`, `Глава 1`, `Часть 2`, `Пролог`, `Эпилог`.

### Мотивация

- **XP** за чтение (3 XP в минуту), главы (+25), книги (+100), верные ответы (+10), задания и достижения.
- **Огонёк** — серия дней с выполненной целью. Заморозка автоматически спасает серию при пропуске (до 3 штук, 50 перьев).
- **Цель дня**: 5/10/15/20/25/30/45 минут. Достигнутая цель фиксируется на день, даже если потом изменить настройку.
- **Три задания дня** и бонус за все три.
- **16 достижений**, уровни с титулами от «Новичка с фонариком» до «Совы-архивариуса».
- **Лига**: недельный рейтинг с тренировочными соперниками; XP считается настоящий.
- **Сундуки саг** за полное собрание серии.

### Данные

Всё хранится локально в `localStorage` под ключом `sova.state.v1`:

- прогресс и позиции чтения;
- XP, перья, огонёк, достижения, задания;
- свои книги и саги;
- настройки читалки и звука.

Ничего не отправляется в сеть. Очистка данных сайта в браузере удалит прогресс. Свои книги лучше хранить и в исходном файле.

## Тесты

Откройте <http://127.0.0.1:8123/tests/test.html> — тесты запускаются сразу.

Проверяются: чистое состояние, имя, цели, XP за чтение, завершение глав и книг, квизы, серия, фиксация достигнутой цели, задания и бонус, достижения, сундук саги, демо-профиль, уровни и разбор текста на главы.

Перед прогоном данные приложения сохраняются, после — восстанавливаются. Всего 17 проверок.

`tests/mobile.html` — превью приложения в iframe шириной 390 px с диагностикой горизонтального переполнения:

```text
http://127.0.0.1:8123/tests/mobile.html?path=%2F%3Fseed%3Ddemo%23%2Fhome
```

## Технические решения

- Ванильные HTML/CSS/JS, классические скрипты и глобальные объекты — без сборщика и ES-модулей.
- Mobile-first, safe-area для Android/iOS, нижняя навигация, листы снизу.
- Никаких внешних запросов: шрифты системные, иконки — inline SVG, звук — Web Audio API.
- Service worker кэширует оболочку и отдаёт `index.html` при офлайн-переходе.
- Версия кэша задаётся в `sw.js` (`CACHE_NAME`). После изменения файлов оболочки её нужно увеличить, иначе установленное приложение продолжит отдавать старые скрипты из кэша.

## Известные ограничения

- Лига и соперники тренировочные: их XP генерируется детерминированно для демонстрации.
- Синтез речи зависит от доступных голосов Web Speech API; на некоторых сборках Android русский голос может отсутствовать.
- Внутренняя библиотека демонстрационная; свои книги хранятся только в текущем браузере.
- Это не заменяет резервное копирование: очистка данных браузера удалит библиотеку и прогресс.
